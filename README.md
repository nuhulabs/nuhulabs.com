## Developing
Requirements: `zig` ([version](https://github.com/nurulhudaapon/nuhu.dev/blob/main/build.zig.zon#L5))

Start dev server (http://localhost:3000):
```bash
zig build dev
```

Build static site (output in `dist/`):

```bash
zig build zx -- export
```
Built with

- Ziex: https://ziex.dev
- Zig: https://ziglang.org
